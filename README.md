This dataset is extracted from Scopus with an original total of 2,577 publications, with 749 as the final total after strict filters. Graphs generated using the open-source bibliometrix R package. # Bibliometric Analysis of Research Findings

This repository contains the visual findings, graphs, and analytical scripts generated using the open-source **bibliometrix** R package (and/or Biblioshiny). The core focus of this repository is to share the structural and trend maps derived from our bibliometric research.
